A one-day broadsheet that sums up 22 November 2026's world news in one
1024×1024 image: four large story fronts (Mexico's capture of the cartel
boss 'El Chapo Isidro', Iran's claimed tanker strike in the Gulf, Russia's
overnight barrage on Ukraine's grid, COP31 running into overtime), each with
a big legible headline and a short attributed sub-line, plus an ALSO TODAY
strip (Peru's 6.9 quake, the FBI database breach review, steady markets).
Rebuilt from judge feedback on the earlier dense version: no micro-text,
no hype badges or gauges, every number stated once, and every text element
verified legible at 300 px. Four AI-generated editorial panels under a
hand-built HTML layer, screenshotted at 2× and downsampled for crisp text.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
