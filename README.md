A newspaper front page that sums up 22 November 2026's world news in one
1024×1024 image: six photo fronts (Mexico's cartel raid, the Gulf
confrontation, Russia's barrage on Ukraine, the Peru quake, COP31 overtime,
the FBI database hack), a TODAY IN NUMBERS tally strip, and three equal
columns — THE TALLY (crime, death and survival counters with a toll bar
chart), THE WIRE (15 briefs across six regions), and MARKETS & CRYPTO
(year-to-date loss chart, 24-hour liquidation bars, a fear-and-greed gauge
and Bitcoin, Ether, gold and ETF-flow rows). Rendered from a hand-built HTML
layer over AI-generated editorial panels, screenshotted at 2× and downsampled
for crisp text.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
